Fix macOS app bundle signing for Apple Silicon and Intel downloads.

- Apply ad-hoc code signing to the complete macOS app bundle, including the bundled CLI. The previous release failed macOS bundle signature verification.
- Verify signatures in the built app, extracted updater archive, and mounted DMG before the release workflow can complete.
- Recording, memory storage, and Windows/Linux behavior are unchanged.

### macOS installation

Choose the Apple Silicon (`aarch64`) or Intel (`x64`) DMG and move Lore to Applications, replacing an older copy if necessary.

Ad-hoc signing does not verify the developer's identity and does not include Apple notarization. macOS may still block the downloaded app. If offered, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it. This release does not promise warning-free installation.

Tauri update signatures remain enabled and use the existing update key. They are separate from macOS code signing. Windows builds still have no code-signing certificate.
