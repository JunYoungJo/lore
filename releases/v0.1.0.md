Lore’s first desktop release for source-linked project memory across Claude Code, Codex, and multiple PCs.

- Record decisions, reasons, and lessons as topic-based Markdown with links to saved conversations.
- Set up coding tools, memory folders, and qmd search from the guided introduction and Manage Lore window.
- Inspect current recording, waiting sessions, recent notes, and work needing attention from the tray.
- Review local changes before committing; compare evidence and the final diff when Git histories diverge.
- Select recording models and supported effort, manage the local embedding model, and choose a system, light, or dark appearance.
- Check for signed app updates from the tray menu or Settings. Installation is explicit and waits for recording, sync, review, and setup work to finish.

### Downloads

- macOS: choose the Apple Silicon (`aarch64`) or Intel (`x64`) DMG. Move Lore to Applications before running it.
- Windows: use the `x64-setup.exe` NSIS installer. MSI packages are not published.
- Linux: AppImage supports in-app updates. DEB installations are updated by installing a newer package.

These builds do not have Apple Developer ID signing/notarization or a Windows code-signing certificate. Operating-system security warnings may appear. The Tauri signature protects app updates; it is separate from OS code signing.

### Before use

An authenticated Claude Code or Codex CLI, qmd, and Git are required for the corresponding features. Setup helps prepare them. Recording sends the necessary conversations and notes to the selected CLI’s model provider and uses that account’s allowance. Memory and source conversations stay in the folder you choose; Git sharing includes all committed files in that memory repository.

This is an early release. Check important memories against their source conversations and inspect sync decisions before applying them. Setup completion is separate from verifying recording and recall in your own project.
